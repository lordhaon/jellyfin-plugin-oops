OOPS – Out Of Place Sorter

Oops, wrong library? Open the ⋮ menu on any movie, show, season, episode, album or book and pick Transfer media. Select several items first to move them all at once. Only administrators see the option.

Copies watched, resume position, favorites and ratings for every user onto the moved items.
Only folders with nothing left in them are deleted. Library root folders are never touched.
